# /kiln:track

Knowledge: the `music` skill (brief, composing without hearing, rendering, gates) and
`procedural-audio` (`audio_check.py`). Agents cannot listen: every claim about the track is a
measurement or the user's ear.

1. **Brief, one question.** Mood and use (standalone listening, a video background, a game loop
   or stinger); length; vocals and lyrics or instrumental; tempo and key if the user cares
   (➡️ chosen from the mood, music skill §2); references described in words. Never imitate a
   named living artist's voice or a specific song.
2. **Task.** `tasks/TASK-NNN.md` (`type: music`, `role: composer`, paths `out/<track>/` in asset
   mode), backlog line, gates table from `pipeline.py gates --suggest`.
3. **Route.**
   - **Composed** (always available): `kiln:composer` writes MIDI from a cue spec with the theory
     checks and `kiln:music-producer` renders it (music skill §2-3). No generator, no licence
     questions; the best route for game loops with exact lengths.
   - **Generated**, only as `audio_generators` allows (agents never change it; with `off` say
     how: `/kiln:settings audio_generators=local`). `local` / `remote`: `tools_check.py offers
     --project .` compares (ACE-Step 1.5: MIT, outputs usable commercially, < 4 GB, songs with
     vocals up to 10 min; DiffRhythm 1.2: Apache-2.0, 8 GB, songs from timed lyrics), install
     on the yes; `remote` through `gpu_job.py`. `api`: name the service's terms before the first
     call (ElevenLabs Music: commercial use except film, TV, radio and big-studio games, no
     downloads on the free plan; Suno: commercial only on paid plans and only for tracks
     downloaded within the plan's cap); the key comes from an environment variable. Never
     offered: MusicGen and YuE (non-commercial weights), Udio (no downloads). Record prompt,
     seed, model and commit.
4. **Gates** (`audio_check.py`, music skill §4), in the task file:
   - standalone or video: integrated loudness -14 LUFS ±1, true peak ≤ -1 dBTP;
   - game music: the project's target (music skill, default -19 LUFS ±1), ≤ -1 dBTP; a loop has
     the exact sample length of its bars and a seam under the 99th-percentile step;
   - tempo ±1 BPM and key as briefed; length as briefed ±2 s (loops exact);
   - `kiln:qa-audio` measures, `kiln:verifier` closes; the user's listen is the last word on
     taste (`user_gates`).
5. **Deliver** into `out/<track>/` (asset mode) or the task's paths: master WAV 48 kHz 24-bit
   (resample generator output: 44.1 or 32 kHz), OGG Vorbis for games or MP3 320 kb/s for
   sharing, stems when composed, `README.md` (duration, BPM, key, LUFS, true peak, how it was
   made: score or model + commit + licence + prompt + seed), the licence row in
   `production/LICENSES.md`. A purely generated track is not copyrightable in the US (prompts
   alone are not authorship, US Copyright Office 2025): say so; a composed one is the user's.
6. **Report** in the user's language: the numbers, where the files are, what to listen for.
